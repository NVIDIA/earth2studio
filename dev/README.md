# Development Documentation

This temporary directory keeps humans and agents aligned while Earth2Studio 1.0
is under active design. It avoids repeatedly updating formal documentation before
the APIs stabilize.

The directory contains three collections:

1. **Specs:** Concise, human-focused descriptions of core design directions.
2. **Examples:** Short, notebook-like Python scripts demonstrating intended usage.
3. **Scratch:** Research, exploratory notes, and other useful non-normative context.

Once the design stabilizes, relevant content will move into the user guide and
formal documentation, and this directory will be removed.
