SamudrACE Lexicon

Maps Earth2Studio variable names to the variable labels used by the FME
CoupledStepper of the SamudrACE coupled atmosphere-ocean emulator. Covers
both the ACE2 atmosphere (CM4 model levels) and the Samudra ocean
(depth-based naming) variables. Users may also access the
``get_e2s_from_fme`` method to get the reverse mapping.

Ocean variables use depth-based names with 'p' replacing decimal points
(e.g. ``thetao2p5m`` for 2.5 m depth, ``so250m`` for 250 m depth).

**Examples:**

<CodeBlock showLineNumbers={false}>

```python
>>> from earth2studio.lexicon.samudrace import SamudrACELexicon
>>> SamudrACELexicon["u10m"]
("UGRD10m", <function mod at 0x...>)
>>> SamudrACELexicon.get_e2s_from_fme("thetao_0")
"thetao2p5m"
```

</CodeBlock>
