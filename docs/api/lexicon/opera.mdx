<Indent>

Lexicon for EUMETNET OPERA composite radar data.

Maps Earth2Studio variable names to ODIM HDF5 quantity codes stored inside
the composite files.

<Note>

Variable documentation:
https://eumetnet.github.io/openradardata-documentation/

</Note>
