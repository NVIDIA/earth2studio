Apply metric to data `x` and `y`, checking that their coordinates
are broadcastable. While reducing over `reduction_dimensions`.

**Parameters:**

<ParamField path="x" type="torch.Tensor">
Input tensor #1 intended to apply metric to. `x` is typically understood
to be the forecast or prediction tensor.
</ParamField>

<ParamField path="x_coords" type="CoordSystem">
[`CoordSystem`](../utils/type.mdx#earth2studio-utils-type-CoordSystem) — Ordered dict representing coordinate system that describes the `x` tensor.
`reduction_dimensions` must be in coords.
</ParamField>

<ParamField path="y" type="torch.Tensor">
Input tensor #2 intended to apply statistic to. `y` is typically the observation
or validation tensor.
</ParamField>

<ParamField path="y_coords" type="CoordSystem">
[`CoordSystem`](../utils/type.mdx#earth2studio-utils-type-CoordSystem) — Ordered dict representing coordinate system that describes the `y` tensor.
`reduction_dimensions` must be in coords.
</ParamField>

</Indent>
