<Indent>

A backend that supports the zarr format.

**Parameters:**

<ParamField path="file_name" type="str" default="None">
Optional name to provide to the zarr store, if provided then this function
will create a directory store with this file name. If none, will create a
in-memory store., by default None
</ParamField>

<ParamField path="chunks" type="dict[str, int]" default="&#123;'ensemble': 1, 'time': 1, 'lead_time': 1, 'variable': 1&#125;">
An ordered dict of chunks to use with the data passed through data/coords, by
default &#123;&#125;
</ParamField>

<ParamField path="backend_kwargs" type="dict[str, Any]" default="&#123;'overwrite': False&#125;">
Key word arguments for zarr.Group root object, by default &#123;"overwrite": False&#125;
</ParamField>

<ParamField path="zarr_codecs" type="CompressorsLike" default="None">
Compression codec to use when creating any new arrays. Only effects Zarr 3.0.
If None, will use no compressor, by default None
</ParamField>

<Note>

For keyword argument options see: https://zarr.readthedocs.io/en/latest/api/zarr/index.html#zarr.group

</Note>

Add an array to the existing zarr group.

**Parameters:**

<ParamField path="coords" type="CoordSystem">
[`CoordSystem`](../utils/type.mdx#earth2studio-utils-type-CoordSystem) — Ordered dict of coordinate information.

<ParamField path="array_name" type="str">
Name to add to zarr group for the new array.
</ParamField>

<ParamField path="data" type="torch.Tensor | list[torch.Tensor]" default="None">
Optional data to initialize the array with. If None, then
the array is NaN initialized (zarr default).
Can also pass a list of tensors, which must match in length to the
list of array_names passed. If a list of tensors is passed, it is assumed
that each tensor share `coords`.
</ParamField>

Optional keyword arguments passed to zarr dataset constructor.
