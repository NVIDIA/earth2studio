Earth2Studio REST API server.

Provides FastAPI endpoints for workflow execution, status, and result retrieval,
with Redis and RQ for job queuing and Prometheus metrics.

<Indent>

Check if the inference request can be admitted based on queue sizes.

Checks all relevant queues (inference, result zip, object storage,
and finalize metadata) to ensure none are at capacity before allowing
a new request to be enqueued.

**Parameters:**

<ParamField path="sync_redis" type="redis.Redis">
Synchronous Redis client.
</ParamField>

**Raises:**

- `HTTPException`: 429 if any queue is full (service temporarily unavailable; retry later).
500 if queue status cannot be determined.

</Indent>

Enqueue the single exposed workflow for execution.

This endpoint is only valid when exactly one workflow is exposed (same notion
of *exposed* as ``GET /v1/infer/workflows``). If zero or more than one workflow
is exposed, the request fails.

**Parameters:**

<ParamField path="request" type="WorkflowExecutionRequest">
[`WorkflowExecutionRequest`](#earth2studio-serve-server-main-WorkflowExecutionRequest) — Request body containing workflow parameters for the selected workflow.
</ParamField>

<ParamField path="sync_redis" type="SyncRedis">
[`SyncRedis`](./dependencies.mdx#earth2studio-serve-server-dependencies-SyncRedis) — Synchronous Redis client (injected).
</ParamField>

<ParamField path="queue" type="InferenceQueue">
[`InferenceQueue`](./dependencies.mdx#earth2studio-serve-server-dependencies-InferenceQueue) — RQ inference queue (injected).
</ParamField>

**Returns:** [`WorkflowExecutionResponse`](#earth2studio-serve-server-main-WorkflowExecutionResponse)

Execution ID, status (QUEUED), queue position, and message.

**Raises:**

- `HTTPException`: 503 if no exposed workflows are registered; 409 if more than one exposed
workflow; otherwise same status codes as ``POST /v1/infer/&#123;workflow_name&#125;``.

</Indent>

Validates parameters, performs admission control, persists execution data
in Redis, and enqueues the job to the RQ inference queue.

</ParamField>

<ParamField path="request" type="WorkflowExecutionRequest">

</ParamField>

<ParamField path="sync_redis" type="SyncRedis">

</ParamField>

Stream a specific file from the workflow execution results.

If filepath equals the request ID (workflow_name:execution_id), streams the
results zip file. Otherwise serves a file from the output directory (path
normalized and checked to prevent directory traversal).

**Parameters:**

<ParamField path="workflow_name" type="str">
Name of the workflow.
</ParamField>

<ParamField path="execution_id" type="str">
Execution identifier.
</ParamField>

<ParamField path="filepath" type="str">
Relative path within the output directory, or the request ID for the zip.
</ParamField>

<ParamField path="sync_redis" type="SyncRedis">
[`SyncRedis`](./dependencies.mdx#earth2studio-serve-server-dependencies-SyncRedis) — Synchronous Redis client (injected).
</ParamField>

<ParamField path="async_redis" type="AsyncRedis">
[`AsyncRedis`](./dependencies.mdx#earth2studio-serve-server-dependencies-AsyncRedis) — Async Redis client (injected).
</ParamField>

**Returns:** `StreamingResponse`

File or zip contents with appropriate headers.

**Raises:**

- `HTTPException`: 403 on path traversal attempt; 404 if workflow, execution, file, or zip
not found or results not completed; 500 on error.

</Indent>
