```python
earth2studio.serve.server.utils.queue_next_stage(
    redis_client: redis.Redis,
    current_stage: earth2studio.serve.server.utils.Stage,
    workflow_name: str,
    execution_id: str,
    output_path_str: str,
    results_zip_dir_str: str | None = None
) -> str | None
```

</CodeBlock>

<Indent>

Queue the next pipeline stage based on configuration.

Pipeline flow:
- If result_zip_enabled: inference -&gt; result_zip -&gt; object_storage (if enabled) -&gt; [geocatalog_ingestion (if request had geo_catalog_url)] -&gt; finalize
- If not result_zip_enabled: inference -&gt; object_storage (if enabled) -&gt; [geocatalog_ingestion (if request had geo_catalog_url)] -&gt; finalize

**Parameters:**

<ParamField path="redis_client" type="redis.Redis">
Redis client for queue connection
</ParamField>

<ParamField path="current_stage" type="Stage">
[`Stage`](#earth2studio-serve-server-utils-Stage) — The stage that just completed ("inference", "result_zip", "object_storage", "geocatalog_ingestion")
</ParamField>

<ParamField path="workflow_name" type="str">
Name of the workflow
</ParamField>

<ParamField path="execution_id" type="str">
Execution ID of the workflow
</ParamField>

<ParamField path="output_path_str" type="str">
Path to the output files
</ParamField>

<ParamField path="results_zip_dir_str" type="str | None" default="None">
Directory for result zips (required when queuing result_zip)
</ParamField>

**Returns:** `str | None`

The RQ job ID if queued successfully, None on error

</Indent>
