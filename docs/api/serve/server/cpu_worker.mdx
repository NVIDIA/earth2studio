<Indent>

RQ Worker function to finalize metadata and optionally upload workflow results to object storage.

This function is intended to be executed by the CPU worker from the object_storage_queue.
It always creates the final metadata file, and optionally uploads to S3 and generates
a CloudFront signed URL if object storage is enabled.

For Azure, account and container are parsed from ``container_url`` in the workflow
request parameters (pending metadata) when present. If ``container_url`` is absent,
the upload step is skipped and the pipeline continues successfully. If
``geo_catalog_url`` is set on the request and an upload ran, it is stored in Redis
``storage_info`` for GeoCatalog ingestion.

**Parameters:**

<ParamField path="workflow_name" type="str">
Name of the workflow
</ParamField>

<ParamField path="execution_id" type="str">
Execution ID of the workflow
</ParamField>

<ParamField path="output_path_str" type="str">
Path to the output files (as string for serialization)
</ParamField>

**Returns:** `dict[str, Any] | None`

Dict containing result info, None on critical failure

</Indent>
