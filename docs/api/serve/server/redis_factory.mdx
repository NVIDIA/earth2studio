Centralized Redis client factory for worker processes.

Worker processes (RQ) run in separate OS processes and cannot access FastAPI's
app.state. This module provides a single factory function so all Redis client
construction is defined in one place.

## Module Contents

### Functions

| Name | Description |
|------|-------------|
| [`create_async_redis_client`](#earth2studio-serve-server-redis_factory-create_async_redis_client) | Create an async Redis client from the current server configuration. |
| [`create_sync_redis_client`](#earth2studio-serve-server-redis_factory-create_sync_redis_client) | Create a synchronous Redis client from the current server configuration. |
| [`get_worker_redis_client`](#earth2studio-serve-server-redis_factory-get_worker_redis_client) | Singleton Redis client for RQ worker processes. |
