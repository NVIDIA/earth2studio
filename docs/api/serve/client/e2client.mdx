Prognostic model wrapper for inference output data sources.

Wraps an InferenceOutputSource to provide a prognostic model interface that
can be used in Earth2Studio workflows. Pre-computed inference results are
consumed as if generated by a live model.

**Parameters:**

<ParamField path="data_source" type="InferenceOutputSource">
[`InferenceOutputSource`](../../data/xr.mdx#earth2studio-data-xr-InferenceOutputSource) — Pre-computed inference data source.
</ParamField>

<ParamField path="iter_coord" type="(time, lead_time)" default="'time'">
Coordinate to iterate over. Default is "lead_time".
</ParamField>

<ParamField path="variables" type="list[str]" default="None">
Variable names to include. If None, uses all from the data source.
</ParamField>

<ParamField path="device" type="torch.device or str" default="'cpu'">

</ParamField>
