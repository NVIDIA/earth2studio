Flatten dimensions into a leading batch dimension.

**Parameters:**

<ParamField path="dims" type="Sequence[Hashable]">
Dimensions to flatten, ordered within the new batch dimension.
</ParamField>

<ParamField path="batch_dim" type="Hashable" default="'batch'">
Name of the flattened dimension, by default "batch"
</ParamField>

<ParamField path="contiguous" type="bool" default="True">
Make copied data contiguous when a view is not possible, by default True
</ParamField>

**Returns:** `xr.DataArray`

DataArray with a leading flattened batch dimension.

**Raises:**

- `ValueError`: If dimensions are invalid, the array is already batched, or copying is
required while ``contiguous`` is False.
- `NotImplementedError`: If a coordinate spans batched and unbatched dimensions.
- `TypeError`: If the DataArray is not backed by NumPy or CuPy.

</Indent>

<Indent>

Wrap a Torch tensor and coordinate system in an xarray DataArray.

CPU tensors share memory with a NumPy-backed DataArray. CUDA tensors share memory
with a CuPy-backed DataArray through DLPack.

**Parameters:**

<ParamField path="tensor" type="torch.Tensor">
Tensor containing the data.
</ParamField>

<ParamField path="coords" type="CoordSystem">
[`CoordSystem`](./type.mdx#earth2studio-utils-type-CoordSystem) — Ordered coordinate mapping with one entry per tensor dimension.
</ParamField>

<ParamField path="name" type="Hashable | None" default="None">
DataArray name, by default None
</ParamField>

<ParamField path="attrs" type="Mapping[Any, Any] | None" default="None">
DataArray attributes, by default None
</ParamField>

<ParamField path="requires_grad" type="bool" default="False">
Request autograd-enabled conversion, by default False
</ParamField>

**Returns:** `xr.DataArray`

DataArray sharing memory with the input tensor.

**Raises:**

- `ValueError`: If coordinate dimensions do not match the tensor shape.
- `TypeError`: If the tensor is not on a CPU or CUDA device.
- `ImportError`: If a CUDA tensor is provided without CuPy installed.
- `NotImplementedError`: If ``requires_grad`` is True.

</Indent>
