<Indent>

Cast a datetime64 array to nanosecond precision when representable.

Nanosecond precision is the Earth2Studio default, since it preserves the
sub-second resolution some observation data sources carry. Times outside the
``datetime64[ns]`` range would wrap to unrelated dates if cast, so the
array's own precision is kept instead.

**Parameters:**

<ParamField path="time" type="np.ndarray">
Numpy datetime64 array
</ParamField>

**Returns:** `np.ndarray`

The array as ``datetime64[ns]`` when representable, otherwise unchanged

</Indent>

<Indent>

Normalize a TimeTolerance to a tuple of (lower_bound, upper_bound) as np.timedelta64.

**Parameters:**

<ParamField path="tolerance" type="TimeTolerance">
[`TimeTolerance`](./type.mdx#earth2studio-utils-type-TimeTolerance) — Time tolerance value. Can be:
- A single timedelta or np.timedelta64 (interpreted as symmetric +/- bounds)
- A tuple of (timedelta, timedelta) or (np.timedelta64, np.timedelta64)
  (interpreted as (lower_bound, upper_bound))
</ParamField>

**Returns:** `tuple[np.timedelta64, np.timedelta64]`

Tuple of (lower_bound, upper_bound) as np.timedelta64 values.
For a single tolerance value, returns (-tolerance, +tolerance).
For a tuple, returns the normalized bounds.

**Examples:**

<CodeBlock showLineNumbers={false}>

```python
>>> normalize_time_tolerance(np.timedelta64(1, "h"))
(numpy.timedelta64(-3600,'s'), numpy.timedelta64(3600,'s'))
```

</CodeBlock>

<CodeBlock showLineNumbers={false}>

```python
>>> normalize_time_tolerance((np.timedelta64(-2, "h"), np.timedelta64(3, "h")))
(numpy.timedelta64(-7200,'s'), numpy.timedelta64(10800,'s'))
```

</CodeBlock>

</Indent>
