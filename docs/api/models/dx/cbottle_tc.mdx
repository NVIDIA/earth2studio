Climate in a Bottle tropical cyclone guidance diagnostic.
This model for Climate in a Bottle (cBottle) allows users to provide an cyclone
guidance map on a lat-lon grid and synthesis global climate realizations at that
given time. The tropical cyclone guidance field is regridded to HPX Level 3, which
is then used during the sampling process.

**Badges:** `region:global` `class:climate` `product:wind` `product:precip` `product:temp` `product:atmos` `year:2025` `gpu:80gb` `provider:nvidia` `backend:pytorch`

**Parameters:**

<ParamField path="core_model" type="torch.nn.Module">
Core Pytorch diffusion model
</ParamField>

<ParamField path="classifier_model" type="torch.nn.Module">
Pytorch classifier model
</ParamField>

<ParamField path="sst_ds" type="xr.Dataset">
Sea surface temperature xarray dataset
</ParamField>

<ParamField path="lat_lon" type="bool" default="True">
Lat/lon toggle, if true the model will return output on a 0.25 deg lat/lon
grid. If false, the native nested HealPix grid will be returned, by default True
</ParamField>

<ParamField path="sampler_steps" type="int" default="18">
Number of diffusion steps, by default 18
</ParamField>

<ParamField path="sigma_max" type="float" default="200.0">
Noise amplitude used to generate latent variables, by default 200
</ParamField>

<ParamField path="batch_size" type="int" default="4">
Batch size to generate time samples at, consider adjusting based on hardware
being used, by default 4
</ParamField>

<ParamField path="seed" type="int" default="None">
Random generator seed for latent variables. If None will use no seed, by default
None
</ParamField>

<ParamField path="dataset_modality" type="DatasetModality" default="DatasetModality.ERA5">
[`DatasetModality`](#earth2studio-models-dx-cbottle_tc-DatasetModality) — Dataset modality label to use when sampling (0=ICON, 1=ERA5), by default
DatasetModality.ERA5
</ParamField>

<Note>

For more information see the following references:

- https://arxiv.org/abs/2505.06474v1
- https://github.com/NVlabs/cBottle
- https://catalog.ngc.nvidia.com/orgs/nvidia/teams/earth-2/models/cbottle
- https://huggingface.co/nvidia/cbottle
This model provides the function `model.create_guidance_tensor`
as a utility to create the input guidance tensor.

</Note>

Compute classifier-guided log-odds ratio for one guidance sample.

**Parameters:**

<ParamField path="x" type="torch.Tensor">
Input guidance tensor with the same layout expected by `__call__`.
</ParamField>

<ParamField path="coords" type="CoordSystem">
[`CoordSystem`](../../utils/type.mdx#earth2studio-utils-type-CoordSystem) — Coordinate system associated with ``x``.
</ParamField>

<ParamField path="guidance_scale" type="float" default="128">
Guidance scale forwarded to cBottle odds-ratio evaluation. Defaults to 128.
</ParamField>

<ParamField path="compute_forward_divergences" type="bool" default="False">
If True, compute forward-phase Hutchinson divergence terms. These are
not required for ``log_odds_ratio`` and increase runtime; by default False.
</ParamField>

**Returns:** `tuple[float | torch.Tensor, torch.Tensor,` [`CoordSystem`](../../utils/type.mdx#earth2studio-utils-type-CoordSystem) `]`

log_odds_ratio, forward_latents, latent_coords

<Note>

This method requires the underlying cBottle model to be loaded with
``allow_second_order_derivatives=True`` via `load_model`. The default
``allow_second_order_derivatives=False`` path is optimized for standard guided
sampling and fails for odds-ratio computations.

</Note>
