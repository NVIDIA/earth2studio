Precipitation diagnostic for the DLESyMv0_ISCCP_ERA5 climate model.

A ``HEALPixUNet`` diagnostic from the AtmosSci-DLESM/DLESyM repository
that predicts 6-hourly accumulated precipitation (``tp06``) from the full
coupled atmosphere/ocean state. It is designed to be chained off
[`DLESyMv0_ISCCP_ERA5`](../px/dlesym_v0_isccp_era5.mdx#earth2studio-models-px-dlesym_v0_isccp_era5-DLESyMv0_ISCCP_ERA5) (or its lat/lon
variant).

The model takes 2 consecutive history timesteps of 10 variables (the 9
atmospheric variables plus ``sst``) on a HEALPix ``nside=64`` grid and
predicts ``tp06`` at the last input timestep (i.e., precipitation
accumulated over the 6 h prior to ``t=0``).

When ``use_ttr=True`` (default), the wrapper accepts ERA5 ``ttr`` in
place of ``rlut`` and applies the same per-doy moment-matching TTR -&gt; OLR
transform as
[`DLESyMv0_ISCCP_ERA5`](../px/dlesym_v0_isccp_era5.mdx#earth2studio-models-px-dlesym_v0_isccp_era5-DLESyMv0_ISCCP_ERA5)
before the forward pass. This allows the diagnostic to run standalone
from an ERA5 initial condition. When ``use_ttr=False``, supply
pre-transformed ``rlut`` directly -- use this when chaining off
[`DLESyMv0_ISCCP_ERA5`](../px/dlesym_v0_isccp_era5.mdx#earth2studio-models-px-dlesym_v0_isccp_era5-DLESyMv0_ISCCP_ERA5) output, which is
already in OLR space.

<Indent>

Convert ERA5 TTR to ISCCP-distributed OLR via per-doy moment matching.

Mirrors the upstream pipeline transform at
nathanielcresswellclay/dlesym_pipeline @ aimip:
``processing/utils/transform_ttr1h_olr.py``. The transform is per
``(face, height, width, day-of-year)`` so it preserves spatial structure
while matching the per-pixel marginal distribution to ISCCP OLR.

**Parameters:**

<ParamField path="x" type="torch.Tensor">
Input tensor with the TTR channel at axis ``-4``; shape
``(B, T, LT, V, F, H, W)``.
</ParamField>

<ParamField path="coords" type="CoordSystem">
[`CoordSystem`](../../utils/type.mdx#earth2studio-utils-type-CoordSystem) — Coordinates carrying ``time`` (datetime64) and ``lead_time``
(timedelta64) used to derive day-of-year per (T, LT) pair.
</ParamField>

<ParamField path="ttr_idx" type="int">
Position of the TTR channel along the variable axis.
</ParamField>

<ParamField path="ttr_clim_mean" type="torch.Tensor">
ERA5 TTR per-doy climatology, shape ``(D, F, H, W)``.
</ParamField>

<ParamField path="ttr_clim_std" type="torch.Tensor">
ERA5 TTR per-doy climatology, shape ``(D, F, H, W)``.
</ParamField>

<ParamField path="olr_clim_mean" type="torch.Tensor">
ISCCP OLR per-doy climatology, same shape.
</ParamField>

<ParamField path="olr_clim_std" type="torch.Tensor">
ISCCP OLR per-doy climatology, same shape.
</ParamField>

<ParamField path="olr_floor" type="float" default="0.0">
Lower bound applied to the transformed OLR (the upstream pipeline
uses a small positive quantile floor). Defaults to 0.0.
</ParamField>

**Returns:** `torch.Tensor`

``x`` with the TTR channel replaced by ISCCP-distributed OLR.

</Indent>
