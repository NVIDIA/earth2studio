HealDA data assimilation model for global weather analysis from sparse
observations on a HEALPix grid.

HealDA is a stateless assimilation model that produces a single global weather
analysis from conventional and satellite observations. It operates on a HEALPix
level-6 padded XY grid and outputs ERA5-compatible atmospheric variables.

The model accepts pre-processed observation DataFrames from
``earth2studio.data.UFSObsConv`` and ``earth2studio.data.UFSObsSat`` and
produces a global analysis field.

**Badges:** `region:global` `class:data-assimilation` `product:wind` `product:temp` `product:atmos` `product:sat` `product:insitu` `year:2026` `gpu:40gb` `provider:nvidia` `backend:pytorch`

</ParamField>

ERA5 per-channel mean for output denormalization [1, out_variables, 1, 1]

</ParamField>

<ParamField path="lat_lon" type="bool" default="False">

regular equiangular lat-lon grid using ``earth2grid``. If False the raw

</ParamField>

<ParamField path="output_resolution" type="tuple[int, int]" default="(181, 360)">
``(nlat, nlon)`` size of the output lat-lon grid. Only used when

</ParamField>

</ParamField>

<Indent>

Convert the per-(sensor, time) observation dict into model-ready tensors.

Observations are laid out **sensor-major, time-minor** in the flat
tensor so that all observations for a given sensor are contiguous:

``[s0_t0, s0_t1, …, s0_tN, s1_t0, s1_t1, …, sK_tN]``

The ``offsets`` tensor (shape [sensors, batch, 1]) stores the
cumulative end-index in that layout, guaranteeing
``offsets[s,:,:] &lt; offsets[s+1,:,:]`` and
``offsets[s,t,:] &lt;= offsets[s,t+1,:]``.

**Parameters:**

<ParamField path="obs_dict" type="dict[str, list[pd.DataFrame | None]]">
Keyed by sensor name (`ALL_SENSORS`).  Each value is a list
of length ``len(request_time)`` with a observation DataFrame per time slot
(or ``None`` when no observations exist for that slot).
</ParamField>

<Indent>

Pre-process, QC-filter, z-score normalize, and split observations by
sensor and request time.

This method handles the full observation pipeline:

1. Convert raw inputs via `prep_conv` / `prep_sat_sensor`.
2. Merge per-channel normalization statistics.
3. Apply QC filters (range checks, height/pressure bounds for conv).
4. Z-score normalize observations.
5. Split into per-sensor, per-time buckets.

**Parameters:**

<ParamField path="conv_obs" type="pd.DataFrame | None">
Raw conventional observation DataFrame (or ``None``)
</ParamField>

<ParamField path="sat_obs" type="pd.DataFrame | None">
Raw satellite observation DataFrame (or ``None``)
</ParamField>

<ParamField path="request_time" type="TimeArray">
[`TimeArray`](../../utils/type.mdx#earth2studio-utils-type-TimeArray) — One or more analysis valid times
</ParamField>

**Returns:** `dict[str, list[pd.DataFrame | None]]`

Dictionary to dictionary mapping sensor name to list of data frames for each
request time.
