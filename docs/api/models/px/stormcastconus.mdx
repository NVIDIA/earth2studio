StormCast-CONUS generative convection-allowing model for the full CONUS domain.

- High-resolution (3km) HRRR state over the Continental United States (99 vars)
- High-resolution land-sea mask and orography invariants
- Coarse resolution (25km) global state (26 vars)

The high-resolution grid is the HRRR Lambert conformal projection
Coarse-resolution inputs are regridded to the HRRR grid internally.

**Badges:** `region:na` `class:nowcasting` `product:wind` `product:temp` `product:precip` `product:radar` `product:atmos` `year:2026` `gpu:24gb` `provider:nvidia` `backend:pytorch`

United States, by default (17, 1041)

</ParamField>

</ParamField>

Low-resolution conditioning variable names, by default

[`DataSource`](../../data/base.mdx#earth2studio-data-base-DataSource) `or` [`ForecastSource`](../../data/base.mdx#earth2studio-data-base-ForecastSource) `or None` — Data source for global conditioning. Required for inference, by default None.
</ParamField>

<ParamField path="conditioning_init_time" type="datetime, list[datetime], TimeArray, or None" default="None">
`datetime, list[datetime],` [`TimeArray`](../../utils/type.mdx#earth2studio-utils-type-TimeArray) `, or None` — Fixed initialisation time for ``conditioning_data_source``. When None,
uses the same conditioning initialization time as the forecast. Useful when
the conditioning is from a forecast source available on a coarser cycle
(e.g. GFS_FX every 6 h while HRRR initialises hourly), by default None.
</ParamField>

<ParamField path="sampler_args" type="dict" default="None">
Overrides for the EDM sampler/scheduler. Recognised keys:
``sigma_min``, ``sigma_max``, ``rho`` (scheduler), and
``S_churn``, ``S_min``, ``S_max``, ``S_noise`` (solver).
Unspecified keys use sensible defaults.
</ParamField>

<ParamField path="num_diffusion_steps" type="int" default="18">
Number of diffusion sampling steps for the EDM (no-obs) path, by default 18.
</ParamField>

<ParamField path="num_sda_diffusion_steps" type="int" default="36">
Number of diffusion sampling steps for the SDA (obs-guided) path, by default 36.
</ParamField>

<ParamField path="batch_size" type="int" default="1">
Maximum batch size processed in one forward pass, by default 1.
</ParamField>

<ParamField path="time_tolerance" type="np.timedelta64, tuple[np.timedelta64, np.timedelta64], or None" default="None">
Time window for filtering observations around each target time.
A single ``np.timedelta64`` creates a symmetric window; a 2-tuple
``(lower, upper)`` is passed directly to ``ObsGridMapping.obs_to_grid``.
``None`` disables time filtering, by default None.
</ParamField>

<ParamField path="sda_std_obs" type="float or dict[str, float]" default="0.1">
Observation noise standard deviation (in physical units) used by the
SDA denoiser when observations are provided. A scalar applies uniformly;
a dict maps variable names to per-variable values (default 0.1 for
unlisted variables). Dict values are converted to normalised units
internally, by default 0.1.
</ParamField>

<ParamField path="sda_dps_norm" type="float" default="2">
Gradient normalisation factor for DPS guidance, by default 2.
</ParamField>

<ParamField path="sda_gamma" type="float" default="0.001">
DPS guidance step size / scale, by default 0.001.
</ParamField>

<ParamField path="use_amp" type="bool" default="True">
Whether to run the diffusion forward pass under ``torch.autocast`` with
bfloat16, by default True.
</ParamField>

<ParamField path="clamp_values" type="bool" default="True">
Whether to apply reflectivity clipping in ``_forward``. When the model is
loaded via `load_model`, this flag is also forwarded to
`_SplitModelWrapper` to enable per-variable physical-minimum clamping,
by default True.
</ParamField>
