What this is / is not

Earth2 precip: six-hour accumulations (mm) from FCN + PrecipitationAFNO, GFS ICs. Display resampled from ~0.25° — not street-scale truth.

MRMS QPE: MultiSensor quantitative precipitation estimate (1 h), summed to the same 6 h windows. Observed rainfall reference — not BREF reflectivity.

Diff: Earth2 minus MRMS on the display grid (exploratory; grids differ in native resolution).

Terrain / 311 / roads: context and complaints only — not inundation depth or emergency guidance.
