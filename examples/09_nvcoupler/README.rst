Coupling (nvcoupler)
--------------------

Examples for nvcoupler, the NUOPC/ESMF-inspired coupling framework for AI
Earth-system inference. All examples run on synthetic toy components — no
model weights, GPU, or network access required — and each prints
hand-verifiable numbers. They cover the coupled atmos/ocean loop, coupling
order experiments, impact chains via accumulation mediators, vertical
(hybrid to pressure) coupling for chemistry, and gradient flow across the
exchange for coupled fine-tuning.
